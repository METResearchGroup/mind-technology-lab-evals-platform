# Evals Harness Platform - Retrospectives

## Overview
This directory contains retrospectives for individual tickets and project phases, documenting what went well, what could be improved, and lessons learned.

## Retrospective Process

### When to Conduct Retrospectives
- After completing each major ticket
- At the end of each project phase
- When encountering significant issues or blockers
- At project completion

### Retrospective Format
Each retrospective should include:
1. **What Went Well**: Positive aspects and successes
2. **What Could Be Improved**: Areas for improvement
3. **Lessons Learned**: Key insights and takeaways
4. **Action Items**: Specific improvements for future work
5. **Metrics**: Relevant performance and quality metrics
